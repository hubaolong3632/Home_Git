# Home_Git

Git 版本控制学习与实践资料库，收录课程作业、综合实践文档与多个 Java/Web 练习项目。

## 项目简介

本仓库为 Git 学习过程中的综合实践归档，包含课堂作业、实验报告、Git GUI 汉化包及多个子项目代码，用于练习分支管理、提交、合并等 Git 操作。

> 默认分支为 `Home_Git`（非 main/master）。

## 目录结构

```
Home_Git/
├── JAVA/                    # Java 练习代码
├── MQ生产消费者/             # 消息队列生产消费者示例
├── get002/                  # Git 操作练习
├── 商城管理系统/              # 商城管理项目
├── 网页制作/                 # 网页制作作业
├── 数据库/                   # 数据库相关练习
├── 内容/                     # 课程内容
├── 第四次作业/               # 第四次作业
├── 第五次内容和作业/          # 第五次作业
├── git-gui-zh-v2.27.0.windows.1/  # Git GUI 中文语言包
├── 22综合实践.docx           # 综合实践报告
└── 第六次课.rar              # 第六次课程资料
```

## 子项目说明

| 目录 | 说明 |
|------|------|
| `JAVA/` | Java 基础与面向对象练习 |
| `MQ生产消费者/` | RabbitMQ 消息队列示例 |
| `商城管理系统/` | 简易商城后台管理 |
| `网页制作/` | HTML/CSS 网页作业 |
| `get002/` | Git 分支与合并练习 |

## 使用方式

```bash
git clone -b Home_Git https://github.com/hubaolong3632/Home_Git.git
cd Home_Git
```

## Git GUI 汉化

`git-gui-zh-v2.27.0.windows.1/` 目录包含 Git for Windows GUI 的中文语言包，可按目录内说明安装。
